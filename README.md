# Dollar Hotel — Website Project

This folder contains the handoff documentation for building the Dollar Hotel website. It's written to be given directly to an AI coding agent (Codex, Antigravity, Claude Code, etc.) so it understands the project without you re-explaining it in chat.

## How to use this with an agent

Point the agent at this folder (or paste `AGENTS.md` + `PRD.md` into its context) and say something like: *"Build this project. Read AGENTS.md first, then PRD.md and TRD.md. Check OPEN-QUESTIONS.md before assuming anything not specified."*

## Files in this package

| File | Purpose |
|---|---|
| `AGENTS.md` | Rules and boundaries for the coding agent — read this first |
| `PRD.md` | Product Requirements — what we're building and why |
| `TRD.md` | Technical Requirements — how it should be built |
| `DESIGN.md` | Visual direction — what to borrow from premium hotel sites and what not to |
| `TASKS.md` | Suggested build order, broken into phases |
| `OPEN-QUESTIONS.md` | Things not yet decided — the agent should flag these, not guess |

## One-line summary of the project

A visually impressive, cinematic Dollar Hotel website that helps customers understand the hotel and its rooms, then sends them to WhatsApp with a pre-filled message — while the owner keeps handling availability, pricing, negotiation, and booking manually through WhatsApp and Excel, as they do today.

## Current status

Requirements gathering is done for the customer-facing concept and admin panel scope. Visual design, exact content (prices, address, rules, real photos), and technical architecture are still open — see `OPEN-QUESTIONS.md`.
